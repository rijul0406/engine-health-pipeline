# Engine Health Data Pipeline

Predictive-maintenance data pipeline on NASA C-MAPSS (FD001) turbofan engine data.

> Work in progress. This README is completed in Phase 9 with the architecture
> diagram, setup steps, measured results, and a limitations section.

Data note: the data is simulated NASA data, not real-world engine data.

## Dataset
Download the C-MAPSS turbofan engine degradation files (FD001 train, test and
RUL) from NASA's Prognostics Data Repository and place them in `data/raw/`.
